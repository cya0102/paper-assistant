# Paper Agent 数据库启动与连接指南

本文档记录 `paper-agent` 日常运行所需的数据库启动、连接、自检和 Migration 指令。

Paper Agent 使用两类数据库：

| 数据库                | 日常配置                         | 用途                                                 |
| --------------------- | -------------------------------- | ---------------------------------------------------- |
| PostgreSQL + pgvector | `localhost:5432/paper_assistant` | 论文、Section、Chunk、Embedding、Evidence 和长期记忆 |
| Redis                 | `localhost:6379/0`               | Agent Checkpoint、Session、短期记忆和中断恢复        |

自动化测试应使用独立的 PostgreSQL 数据库 `paper_agent_test` 和 Redis DB `15`，不要连接日常数据库。

## 1. 每次启动的标准流程

进入项目：

```bash
cd /Users/chenyuan/Documents/develop/paper-assistant
```

启动 PostgreSQL 和 Redis：

```bash
brew services start postgresql@17
brew services start redis
```

查看服务状态：

```bash
brew services list | grep -E 'postgresql|redis'
```

加载 `.env`：

```bash
set -a
source .env
set +a
```

检查必要变量是否已加载；该命令不会显示密码或 API Key：

```bash
uv run python - <<'PY'
import os

names = (
    "PAPER_AGENT_DATABASE_URL",
    "PAPER_AGENT_REDIS_URL",
    "PAPER_AGENT_LLM_PROVIDER",
    "PAPER_AGENT_LLM_MODEL",
    "MIMO_API_KEY",
    "MIMO_BASE_URL",
)

for name in names:
    print(f"{name}: set={bool(os.getenv(name))}")
PY
```

执行数据库连接自检：

```bash
uv run python - <<'PY'
import os
from urllib.parse import urlsplit

from redis import Redis
from sqlalchemy import create_engine, text

database_url = os.getenv("PAPER_AGENT_DATABASE_URL")
redis_url = os.getenv("PAPER_AGENT_REDIS_URL")

if not database_url:
    raise SystemExit("PAPER_AGENT_DATABASE_URL is not set")
if not redis_url:
    raise SystemExit("PAPER_AGENT_REDIS_URL is not set")

engine = create_engine(database_url, pool_pre_ping=True)
with engine.connect() as connection:
    database, user, version = connection.execute(
        text(
            "SELECT current_database(), current_user, "
            "current_setting('server_version')"
        )
    ).one()

print("postgres_database:", database)
print("postgres_user:", user)
print("postgres_version:", version)

parts = urlsplit(redis_url)
print("redis_host:", parts.hostname)
print("redis_port:", parts.port)
print("redis_username_present:", bool(parts.username))
print("redis_password_present:", bool(parts.password))
print("redis_database:", parts.path)
print("redis_ping:", Redis.from_url(redis_url).ping())
PY
```

日常配置的预期结果包括：

```text
postgres_database: paper_assistant
postgres_user: paper_agent
redis_database: /0
redis_ping: True
```

应用最新 Migration：

```bash
uv run paper-agent db-upgrade --database-url "$PAPER_AGENT_DATABASE_URL"
```

检查项目状态：

```bash
uv run paper-agent status \
  --root /Users/chenyuan/Documents/develop/paperAgentTest
```

## 2. `.env` 推荐配置

编辑配置文件：

```bash
cd /Users/chenyuan/Documents/develop/paper-assistant
nano .env
```

参考内容：

```dotenv
PAPER_AGENT_DATABASE_URL='postgresql+psycopg://paper_agent:经过URL编码的数据库密码@localhost:5432/paper_assistant'
PAPER_AGENT_REDIS_URL='redis://:经过URL编码的Redis密码@localhost:6379/0'

PAPER_AGENT_LLM_PROVIDER='mimo'
PAPER_AGENT_LLM_MODEL='mimo-v2.5-pro'
MIMO_API_KEY='你的真实MiMo-Key'
MIMO_BASE_URL='https://api.xiaomimimo.com/v1'

PAPER_AGENT_EMBEDDING_PROVIDER='hashing'
PAPER_AGENT_RERANKER_PROVIDER='lexical'
```

如果 Redis 使用 ACL 用户，URL 应为：

```dotenv
PAPER_AGENT_REDIS_URL='redis://用户名:经过URL编码的Redis密码@localhost:6379/0'
```

注意：

- 不要把真实密码和 API Key 提交到 Git。
- URL 建议使用单引号，避免 `$` 等字符被 Shell 展开。
- MiMo 使用 `MIMO_API_KEY` 和 `MIMO_BASE_URL`，不要映射到 OpenAI 环境变量。
- 切换模型供应商或升级 Checkpoint 格式后，应使用新的 `session_id`。

## 3. PostgreSQL 一次性准备

macOS 本地 PostgreSQL 不一定存在 `postgres` Role。本机管理员用户是 `chenyuan`，使用：

```bash
psql -h localhost -p 5432 -U chenyuan -d postgres
```

查看 Role：

```sql
\du
```

如果没有 `paper_agent`，创建应用 Role：

```sql
CREATE ROLE paper_agent
WITH LOGIN
PASSWORD '替换为实际数据库密码';
```

如果 Role 已存在但需要修改密码：

```sql
ALTER ROLE paper_agent
WITH LOGIN
PASSWORD '替换为实际数据库密码';
```

退出：

```sql
\q
```

创建日常数据库：

```bash
createdb \
  -h localhost \
  -p 5432 \
  -U chenyuan \
  -O paper_agent \
  paper_assistant
```

如果提示 `database already exists`，不要删除数据库，直接继续。

安装 pgvector Extension：

```bash
psql \
  -h localhost \
  -p 5432 \
  -U chenyuan \
  -d paper_assistant \
  -c 'CREATE EXTENSION IF NOT EXISTS vector;'
```

确认 pgvector：

```bash
psql \
  -h localhost \
  -p 5432 \
  -U chenyuan \
  -d paper_assistant \
  -c '\dx vector'
```

应用 Schema：

```bash
uv run paper-agent db-upgrade --database-url "$PAPER_AGENT_DATABASE_URL"
```

查看 Migration 版本：

```bash
psql \
  -h localhost \
  -p 5432 \
  -U paper_agent \
  -d paper_assistant \
  -c 'SELECT * FROM alembic_version;'
```

查看数据库中的项目：

```bash
psql \
  -h localhost \
  -p 5432 \
  -U paper_agent \
  -d paper_assistant \
  -c 'SELECT project_id, name, root_path FROM projects;'
```

项目目录的 Manifest 位于：

```bash
cat /Users/chenyuan/Documents/develop/paperAgentTest/.paper-agent/project.json
```

Manifest 中的 `project_id` 应与 `projects` 表中的对应记录一致。把已有项目切换到全新的空数据库后，应先执行 Migration，再执行一次 `ingest`，让 Pipeline 在数据库中登记项目。

## 4. PostgreSQL 密码包含特殊字符

密码包含 `@`、`:`、`/`、`#`、`?` 等字符时必须进行 URL 编码。

安全输入密码：

```bash
read -s "PAPER_AGENT_DB_PASSWORD?PostgreSQL password: "
echo
export PAPER_AGENT_DB_PASSWORD
```

生成连接 URL：

```bash
export PAPER_AGENT_DATABASE_URL="$(uv run python - <<'PY'
import os
from urllib.parse import quote

password = quote(os.environ["PAPER_AGENT_DB_PASSWORD"], safe="")
print(
    "postgresql+psycopg://"
    f"paper_agent:{password}@localhost:5432/paper_assistant"
)
PY
)"
```

测试连接：

```bash
uv run python -c 'import os; from sqlalchemy import create_engine,text; e=create_engine(os.environ["PAPER_AGENT_DATABASE_URL"]); print(e.connect().execute(text("select current_database() || chr(58) || current_user")).scalar_one())'
```

预期：

```text
paper_assistant:paper_agent
```

## 5. Redis 认证与连接

如果 Redis 没有启用认证，可以使用：

```bash
export PAPER_AGENT_REDIS_URL='redis://localhost:6379/0'
```

本机 Redis 当前启用了认证，应配置真实密码。安全输入密码：

```bash
read -s "PAPER_AGENT_REDIS_PASSWORD?Redis password: "
echo
export PAPER_AGENT_REDIS_PASSWORD
```

默认 Redis 用户的 URL：

```bash
export PAPER_AGENT_REDIS_URL="$(uv run python - <<'PY'
import os
from urllib.parse import quote

password = quote(os.environ["PAPER_AGENT_REDIS_PASSWORD"], safe="")
print(f"redis://:{password}@localhost:6379/0")
PY
)"
```

如果使用 Redis ACL 用户：

```bash
read "PAPER_AGENT_REDIS_USERNAME?Redis username: "
export PAPER_AGENT_REDIS_USERNAME
```

```bash
export PAPER_AGENT_REDIS_URL="$(uv run python - <<'PY'
import os
from urllib.parse import quote

username = quote(os.environ["PAPER_AGENT_REDIS_USERNAME"], safe="")
password = quote(os.environ["PAPER_AGENT_REDIS_PASSWORD"], safe="")
print(f"redis://{username}:{password}@localhost:6379/0")
PY
)"
```

使用 Python 验证 Redis，避免 `redis-cli -u` 显示密码安全警告：

```bash
uv run python -c 'import os; from redis import Redis; print("redis_ping:", Redis.from_url(os.environ["PAPER_AGENT_REDIS_URL"]).ping())'
```

预期：

```text
redis_ping: True
```

错误含义：

| 错误                                       | 含义                                      |
| ------------------------------------------ | ----------------------------------------- |
| `NOAUTH Authentication required`           | URL 没有提供密码                          |
| `WRONGPASS invalid username-password pair` | 用户名、密码错误，或密码没有正确 URL 编码 |
| `Connection refused`                       | Redis 没有启动，或 Host/Port 错误         |
| `KeyError: PAPER_AGENT_REDIS_URL`          | 当前 Shell 没有加载 `.env` 或没有导出变量 |

## 6. 日常 Agent 启动

完成数据库自检后，设置 User 和新 Session：

```bash
export PAPER_AGENT_USER_ID='D3F64C23-BE9B-4D32-A883-29558D4FA3AF'
export PAPER_AGENT_SESSION_ID="$(uuidgen | tr '[:upper:]' '[:lower:]')"
```

执行问答：

```bash
uv run paper-agent ask \
  --root /Users/chenyuan/Documents/develop/paperAgentTest \
  --provider mimo \
  --model mimo-v2.5-pro \
  --user-id "$PAPER_AGENT_USER_ID" \
  --session-id "$PAPER_AGENT_SESSION_ID" \
  '2D-TAN 的主要方法是什么？请给出论文证据。'
```

同一段对话继续使用相同的 `PAPER_AGENT_USER_ID` 和 `PAPER_AGENT_SESSION_ID`。

## 8. 停止服务

日常使用完成后通常可以让 Homebrew 服务继续运行。如果确定需要停止：

```bash
brew services stop redis
brew services stop postgresql@17
```

停止数据库服务不会删除 PostgreSQL 或 Redis 数据。
